# Bedroom (Blender)

Low-poly isometric bedroom scene — replaces Scene 01. Built headlessly with
Blender 5.2.2 by `blender/bedroom/build_bedroom.py`. Every SPEC value
(dimensions, floor plan, prop positions, material hex) is read from
`blender/bedroom/spec.json` — the script never hardcodes scene values.

## Open

- Scene file: `blender/bedroom/bedroom.blend` — regenerated by the build.
  Do not hand-edit; change `build_bedroom.py` or `spec.json` and rebuild.
- Open in the Blender GUI: `open blender/bedroom/bedroom.blend`.
- Collections (real-world metres throughout):
  - `Shell` — floor, 2 back walls with thickness, toilet door (frame + handle)
  - `Furniture` — bed (frame, headboard, mattress, duvet, 2 pillows),
    nightstand, lamp, wardrobe (2 doors + handles), desk, chair
  - `Camera`, `Lights`, named `Materials`

## Build

Reproducible headless build (regenerates the .blend and all renders):

```
/Applications/Blender.app/Contents/MacOS/Blender -b --python blender/bedroom/build_bedroom.py
```

CLI flags:

- `--no-render` — build and save the .blend only, skip renders.
- `--only <collection>` — build a single collection (e.g. `Shell`, `Furniture`).

Camera: orthographic true-iso cutaway — azimuth 45°, elevation ~35.26°,
looking from the open front corner; front walls removed, no ceiling.
